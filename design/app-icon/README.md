# SMART PAPS 앱 아이콘

PAPS 5요인 링: 다섯 조각 링은 PAPS의 다섯 체력요인(심폐지구력·유연성·근력/근지구력·순발력·체지방)을,
골드→코랄 색 변화는 1~5등급 단계를 나타냅니다. 글자는 모두 도형(path)으로 바꿔 두어서 폰트가 없어도 똑같이 보입니다.

| 원본 SVG | 용도 | 만들어진 PNG (`public/icons/`) |
|---|---|---|
| `icon-any.svg` | 둥근 모서리, 크롬 바로가기·바탕화면 | `icon-192.png`, `icon-512.png` |
| `icon-maskable.svg` | 안드로이드 마스크용(가장자리까지 배경, 내용은 안전영역 80% 안) | `icon-maskable-512.png` |
| `icon-full.svg` | 아이폰 홈 화면(iOS가 모서리를 직접 깎음) | `apple-touch-icon.png` (180) |
| `icon-small.svg` | 브라우저 탭 파비콘(문구 없이 PAPS만, 링을 두껍게) | `favicon-32.png`, `favicon-16.png` |

사용 폰트: Archivo 900(Black) — PAPS, IBM Plex Sans KR Bold(700) — 건강체력평가.
